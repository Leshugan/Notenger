# Заметки — сборка APK через GitHub (без компьютера)

Этот проект уже полностью настроен. Тебе нужно только загрузить его на GitHub,
и его бесплатный «робот» сам соберёт APK. Делается всё с телефона в браузере.

---

## ШАГ 1. Создай аккаунт и репозиторий

1. Зайди на **github.com**, зарегистрируйся (бесплатно).
2. Нажми **«+»** в правом верхнем углу → **«New repository»**.
3. Имя: например `notes-app`. Поставь **Public**. Нажми **«Create repository»**.

---

## ШАГ 2. Загрузи файлы проекта

1. На странице репозитория нажми **«uploading an existing file»**
   (или «Add file» → «Upload files»).
2. Загрузи **все файлы и папки** из этого архива.
   - Важно: загрузи именно содержимое папки `notes-app`, а не саму папку.
   - Если телефон не даёт загрузить папку `.github` — см. ШАГ 4 ниже (создашь файл вручную).
3. Внизу нажми **«Commit changes»**.

---

## ШАГ 3. Включи разрешение для робота (делается один раз)

1. В репозитории открой **Settings** (шестерёнка).
2. Слева: **Actions → General**.
3. Найди раздел **«Workflow permissions»**.
4. Выбери **«Read and write permissions»** → **Save**.

---

## ШАГ 4. Если папка `.github` не загрузилась

Некоторые телефоны не загружают скрытые папки. Тогда создай файл вручную:

1. В репозитории: **«Add file» → «Create new file»**.
2. В поле имени впиши ровно так (со слешами):
   ```
   .github/workflows/build.yml
   ```
3. В тело файла вставь содержимое файла `build.yml` из этого архива
   (папка `.github/workflows/build.yml`).
4. **«Commit changes»**.

---

## ШАГ 5. Дождись сборки и скачай APK

1. Открой вкладку **«Actions»** вверху репозитория.
2. Увидишь запущенную сборку «Build Android APK» — идёт 5–10 минут.
   (Если не запустилась сама — открой её и нажми **«Run workflow»**.)
3. Когда появится зелёная галочка — открой этот запуск.
4. Внизу страницы, раздел **«Artifacts»** → скачай **`app-debug-apk`**.
5. Распакуй — внутри `app-debug.apk`.

---

## ШАГ 6. Установи на телефон

1. Открой скачанный `app-debug.apk` через файловый менеджер.
2. Android попросит разрешить **«установку из неизвестных источников»** — разреши.
3. Готово, приложение установится.

---

## Частые вопросы

**APK не подписан для Play Store?**
Это debug-версия — она ставится и работает на твоём телефоне. Для публикации
в Google Play нужна подпись релизным ключом (отдельный шаг, можно добавить позже).

**Хочу просто как сайт/PWA, без APK?**
Файлы `index.html`, `manifest.json` и иконка уже есть. Можно собрать `npm run build`
и залить папку `dist` на Netlify/Vercel, затем в Chrome «Установить приложение».

**Сборка упала с ошибкой?**
Открой неудачный запуск в Actions, посмотри красный шаг. Чаще всего помогает
просто перезапустить: кнопка **«Re-run jobs»**.

## Что внутри проекта

- `src/App.jsx` — само приложение (наш код).
- `src/main.jsx`, `index.html` — точка запуска.
- `package.json`, `vite.config.js` — настройки сборки.
- `capacitor.config.ts` — обёртка в Android-приложение.
- `.github/workflows/build.yml` — инструкция роботу: как собрать APK.
- `resources/icon.png` — иконка приложения (1024×1024).
